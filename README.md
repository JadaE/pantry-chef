# Pantry Chef (Android, Expo / React Native), sideloaded
See PUBLISHING.md for build/host/update. Code: app/App.tsx (tabs + overlays), app/src/screens/* (Pantry, ItemEditor, Recipes, RecipeView, Saved, Shopping, Household, About, ReceiptScan, BarcodeScan, ImportReview),
app/src/logic.ts (pure: dates, expiry, filter/sort, ingredient matching, recipe ranking, shopping list, migration) + app/tests/logic.test.ts,
app/src/receipt.ts (rule-based receipt parser: skip lines, qty/weight, abbreviations, brands) + app/src/groceries.ts (built-in grocery list, fuzzy match, shelf-life table) + app/tests/receipt.test.ts (sample receipts in app/tests/receipts/),
app/src/off.ts (Open Food Facts barcode lookup, User-Agent PantryChef/<ver>), app/src/drafts.ts (import rows → items), app/modules/receipt-ocr (local Expo module, Kotlin, bundled ML Kit Latin text recognition, offline).
app/src/config.ts (the only reader of app/config.local.json / config.example.json), app/src/types.ts (data model), app/src/store.ts (AsyncStorage), app/src/recipes.ts (TheMealDB + cache), app/src/photos.ts, app/src/update.ts.
Cooking mode (v0.0.3): app/src/screens/Cooking.tsx (checklist -> big steps -> Used from pantry), app/src/cooking.ts (pure: time detection, timers, pantry-usage logic), app/src/timers.ts (local notifications), app/src/screens/TimerStrip.tsx; app/tests/cooking.test.ts.
Tests: `cd app && npx tsx tests/logic.test.ts && npx tsx tests/receipt.test.ts && npx tsx tests/config.test.ts && npx tsx tests/cooking.test.ts`. Live recipe smoke test: `npx tsx tests/live-recipes.ts`.
Native: android/ is generated by `expo prebuild` (build-apk.sh runs it only if android/ is missing). After adding a native module or plugin, delete app/android and rebuild.
Setup after cloning: `cd app && npm ci`; optional `cp config.example.json config.local.json` and fill in (see PUBLISHING.md). Without it everything but publishing/update-checks works.
