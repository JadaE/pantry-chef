# Pantry Chef

An Android app (Expo / React Native) for tracking pantry food with expiration dates and amounts, finding recipes from what you have, and building shopping lists.

Features: pantry items with expiry and quantity, recipe browsing (TheMealDB) with bookmarks, shopping list, household view, barcode lookup (Open Food Facts), and an offline receipt scanner (ML Kit text recognition via a local Expo module).

## Run
```bash
cd app
npm install
npm test        # logic and receipt-parser tests
npx expo start
```
Native code under `app/android/` is generated by `expo prebuild` and is not committed. `build-apk.sh` makes a release APK and needs a signing keystore in `keys/` (not in this repo). See `PUBLISHING.md` for hosting notes; site slug and secret paths are placeholders to be filled from local config.

## Not included (set up locally)
- `keys/`: Android signing keystore (`pantrychef.keystore`), `keystore-password.txt`, and `site-config.json` (site slug, install path, update-channel path). Needed by `build-apk.sh`, `tools/make_site.sh` and `publish.sh`.
- `.herenow/`, build output (`dist/`, `publish-site/`) and screenshots.
- Placeholders in the source (`YOUR-SITE-SLUG`, `YOUR_SECRET_PATH`, `YOUR_UPDATE_CHANNEL_PATH`): the in-app update check and Open Food Facts user agent point at them, so replace them with your own values before publishing. Everything else (pantry, recipes, receipt tests) works without them.
- `publish.sh`, `build-apk.sh` and `tools/make_site.sh` still reference the original author's folder (`/workspace/pantry-chef`) and here.now skill path; adjust before running elsewhere.
- Receipt test fixtures in `app/tests/receipts/` are sample text with fake phone/member numbers.
